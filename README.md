# BME Plaisirs d'Hiver - Solution WiFi Outdoor

## Project Overview
The BME Plaisirs d'Hiver project aims to provide a robust and secure outdoor WiFi connectivity solution for the major winter event in Brussels, known as "Plaisirs d'Hiver." This initiative spans over five weeks from late November to early January, focusing on providing seamless internet access across multiple sites. The project includes installation prior to the event, centralized multi-site coverage, user authentication, responsive support, and post-event dismantling.

## Installation
To set up the project locally, follow these instructions:

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd bme-plaisirs-d-hiver
   ```

2. Open the `index.html` file in your preferred web browser to view the project.

## Usage
Once the project is set up, simply open `index.html` in a web browser. You can navigate through the sections which provide information about the project's objectives, technical equipment, site coverage, and demonstration videos.

## Features
- **Multi-site Coverage**: Efficient and centralized WiFi connectivity across various locations.
- **High Capacity Equipment**: Implementation of UniFi Mega Capacity access points capable of handling up to 1,500 simultaneous connections.
- **User Authentication**: Secure access to the network conforming to GDPR requirements.
- **Responsive Support**: 24/7 support during the event period.
- **Budget Breakdown**: Transparent financial planning including costs for installation and materials.
